# FortuneX

Demonstration casino for the FortuneX responsible-gambling commercial. Dark neon theme, demo credits only, no real-money play.

## Film the ad

1. `npm install`
2. `npm run dev`
3. Open [http://localhost:3000/?ad=1](http://localhost:3000/?ad=1)

`?ad=1` skips the age gate and opens filming controls.

### Script beats

| Time | Shot | What to do |
| --- | --- | --- |
| Open | FortuneX on screen | Lobby or Slots |
| One more | Small deposit, then a loss | Add funds → Spin. Use **Next: lose** |
| Larger stakes | Raise chips, keep playing | Change stake, spin again |
| BALANCE: $0 | Screen goes quiet | **Next: bust to $0** or **Show BALANCE $0** |
| Phone | Empty account | `/account` on a phone viewport |
| Close | Brand + message | `/responsible` |

On-screen super **Just one more…** appears after a loss, or tap **Super: one more**.
